Key Problem Addressed

Individuals receive transaction data in scattered, unstructured formats (bank PDFs, UPI records, Excel orders) with cryptic merchant narrations (e.g., "UPI/SWIGGY-19284-DELHI/REST"). Ledger normalizes merchant names, automatically assigns categories, persists records in a structured SQLite database schema, and renders dynamic interactive charts (Pie, Bar, Trend Lines, Inflow vs Outflow).
